# 📊 Advertising Case Study: Model Building & Visualization

## 📌 Overview  
This project analyzes the relationship between advertising spend and sales using machine learning models. It focuses on understanding how different channels (TV, Radio, Newspaper) influence sales.

---

## 🎯 Objectives  
- Analyze advertising dataset  
- Perform Exploratory Data Analysis (EDA)  
- Build regression models  
- Evaluate model performance  
- Visualize insights  

---

## ⚙️ Pipeline  

### 1. Data Loading  
- Load dataset using pandas  
- Inspect data structure  

### 2. Data Preprocessing  
- Handle missing values  
- Select relevant features  
- Train-test split  

### 3. Exploratory Data Analysis (EDA)  
- Correlation heatmap  
- Pairplots  
- Distribution plots  

### 4. Feature Engineering  
- Scaling (if required)  
- Feature selection  

### 5. Model Building  
- Linear Regression  
- Multiple Linear Regression  
- Polynomial Regression (optional)  
- Random Forest (optional)  

### 6. Model Evaluation  
- Mean Absolute Error (MAE)  
- Root Mean Squared Error (RMSE)  
- R² Score  

### 7. Visualization  
- Actual vs Predicted plots  
- Residual plots  
- Feature importance
